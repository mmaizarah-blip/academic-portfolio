# SmartRent — Android Rental Application

## About the Project
SmartRent is an Android application developed as part of my Computer Science studies. It aims to help users explore rental housing options and assess affordability.

## Key Features
- User authentication
- Rental property information
- Rental affordability calculation
- Firebase integration

## Technologies Used
- Java
- Android Studio
- Firebase Authentication
- Cloud Firestore
- APIs

## My Contribution
I contributed to the development of the application, including its Android implementation and integration of relevant services.

## What I Learned
Through this project, I strengthened my understanding of Android application development, database integration, API usage and problem-solving.
